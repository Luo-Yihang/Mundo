## TL;DR

World models capture the structure, appearance, and dynamics of environments to support reconstruction and simulation. Mundo builds such a world from images of a specific place. It represents the scene’s layout and objects in a 3D proxy and defines their physical properties in a scene program. A simulator computes how the objects move and interact, while a video model renders the results using the input images as visual context. You can explore this environment from new viewpoints, modify its objects, and simulate robot tasks within it.
